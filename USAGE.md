# Using the ideas OS

A Domain OS: a wiki knowledge layer + operations + artifacts + governance.

## Add knowledge
Drop sources into `wiki/_source/_inbox/` and run the `wiki-ingest` skill.

## Check health
Run the `os-audit` skill against this OS root.

## Layout
- `wiki/` — the knowledge wiki (start at its `index.md`).
- operations folders — the domain's programs.
- artifacts folders — generated outputs.
- `OS.md` — the manifest; `CLAUDE.md` — governance.
